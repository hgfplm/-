软件清单.csv 使用说明
════════════════════

这是整个软件库唯一需要日常维护的文件，所有软件的信息都在这里。
用 Excel 或记事本编辑均可。

列说明：
  目录       必填。web\soft\ 下的文件夹名，必须和实际文件夹名一致
  名称       显示在门户卡片上的软件名
  分类       浏览器/办公套件/压缩工具/PDF 工具/输入法/通讯协作/系统工具（可自建）
  说明       卡片上的一句话说明
  版本       可留空（自动从安装包文件名识别，如 7z2409-x64.msi → 24.09）
  文件名     安装包文件名。目录里有多个安装包时用它指定用哪个；单文件可留空
  软件源地址 官方下载页/直链，仅作备忘 —— IT 手动下载安装包时从这里获取，
             脚本不会联网下载

标准操作流程（添加一个软件）：
  1. 按清单里的"软件源地址"手动下载安装包
  2. 放入 web\soft\<目录列的文件夹名>\ 下
  3. （目录里有多个文件时）在"文件名"列填上确切文件名
  4. 双击 scripts\更新软件目录.bat —— 门户页面立即更新

更新软件版本：下载新版安装包放入同目录 → 双击 bat（脚本自动选版本号最高的文件）

编辑工具注意：
  用 Excel 编辑保存时请选「CSV UTF-8」格式（文件 → 另存为 → 保存类型选
  CSV UTF-8），普通 CSV 会把中文存成乱码。用记事本 / VS Code 直接编辑无此问题。
